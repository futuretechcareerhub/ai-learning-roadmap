How to use this checklist

Agentic AI courses can vary widely. Some focus on using no-code automation tools, while others expect programming, APIs and application development. This free checklist helps you identify what you can already demonstrate and what you may want to learn next.

Select one option for each statement. This is a personal self-assessment—not a certification exam, admission test, official prerequisite list or guarantee of job readiness.

Mark “Can do” when you can demonstrate the skill independently. If you have only followed a tutorial, “Need practice” may be the more useful answer.

1. Python and software fundamentals

Self-checkCan doNeed practiceNot started
Write Python functions and use lists, dictionaries, loops and conditionals.
Read and write JSON, work with files and handle common exceptions.

Understand basic HTTP requests, APIs, environment variables and secret handling.

Suggested evidence: a small Python project with a README, configuration instructions and safe handling of API keys.

2. LLM and prompt fundamentals

Self-checkCan doNeed practiceNot started
Explain what an LLM does and describe tokens and context windows at a high level.
Write clear prompts with role, task, constraints and expected output.
Request structured output and validate it before using it in application logic.
Recognize hallucinations and know why model output needs verification.

For background, see the Generative AI learning guide.

3. APIs and tool calling

Self-checkCan doNeed practiceNot started
Explain how an AI application can call an external function or API.
Define a tool's purpose, input schema and expected output.
Validate tool arguments and handle timeouts, errors or unexpected responses.
Restrict tools to approved actions and require confirmation for sensitive operations.

Suggested evidence: a demo agent that calls one limited, low-risk tool and includes tests for invalid inputs.

4. RAG and knowledge retrieval

Self-checkCan doNeed practiceNot started
Explain embeddings, chunking and vector search at a practical level.
Build or describe a workflow that retrieves relevant documents for a question.
Check whether retrieved context supports the answer and cite sources when needed.
Identify risks such as stale documents, irrelevant retrieval or sensitive data exposure.

Related reading: RAG vs AI Agents.

5. Agent workflows, state and evaluation

Self-checkCan doNeed practiceNot started
Break a task into steps and define when the workflow should stop or ask for help.
Explain the difference between a simple LLM chain and a tool-using agent workflow.
Track relevant state across steps and avoid retaining unnecessary personal data.
Create test cases for task completion, tool selection, answer quality and failure handling.

Review the Master in Agentic AI guide for broader topics, including architecture, projects, evaluation and deployment.

6. Responsible AI and project readiness

Self-checkCan doNeed practiceNot started
Recognize prompt injection and treat retrieved or user-provided text as untrusted input.
Explain why least-privilege access and human approval matter for agent actions.
Document a project's goal, architecture, data sources, evaluation and limitations.
Explain what the agent must not do and how a person can intervene.

Choosing an Agentic AI course in India

When comparing an Agentic AI course in India, review its actual syllabus, programming prerequisites, project work, feedback process, evaluation coverage, safety topics and schedule. Course titles can vary, so confirm what is currently included rather than assuming every program covers every item in this checklist.

If you are considering a structured program, review Master in Agentic AI at TechPratham and compare the current curriculum, projects and learner support with your goals. Verify the latest course details and terms directly with the provider before making an enrollment decision.

Frequently asked questions

What should I know before taking an Agentic AI course?

It depends on the program. Technical courses may expect Python, APIs and basic software development. Beginner-oriented courses may teach some foundations. Check the provider's published prerequisites.

Is this checklist an official prerequisite or certification test?

No. It is an informal self-assessment for learning planning, not an official entrance exam, credential or assessment from a training provider.

Do I need to know machine learning before Agentic AI?

Some familiarity with AI and LLM concepts is useful, but the depth of machine learning required varies by course and project. Review the curriculum to understand its expectations.

Can non-programmers learn Agentic AI?

Non-programmers can begin by learning concepts and exploring workflow tools, but building custom agents with APIs and frameworks usually requires programming skills. Choose a path that matches your goal and prerequisites.

Does an Agentic AI course guarantee a job?

No course or checklist can guarantee employment or salary outcomes. Results depend on skills, experience, project evidence, interviews and employer requirements.

Will my checklist selections be visible to other visitors?

No. The choices are local to your browser and are not submitted to a shared database. Other visitors cannot see your selections, and refreshing the page may clear them.
